# Asynchronous Server-Side Project

A RESTful expense management API developed as an academic server-side project using **Node.js, Express.js, and MongoDB**.

## Features

* User management
* Personal expense tracking
* Monthly expense reports
* Data storage and retrieval using MongoDB
* RESTful API endpoints
* Asynchronous handling of API requests and database operations

## Technologies

* **JavaScript**
* **Node.js**
* **Express.js**
* **MongoDB**
* **Mongoose**
* **REST APIs**

## Project Structure

The backend is organized into separate components:

* **Routes** – API endpoint definitions
* **Controllers** – Request handling and application logic
* **Models** – Data models and database interaction
* **Middleware** – Request processing and application middleware
* **Config** – Application and database configuration

## About

This project was developed as part of academic coursework to practice **server-side development, RESTful API design, asynchronous programming, and database integration**.
